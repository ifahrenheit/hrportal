Work Week Mode

Switch between 4-day and 5-day work week. This affects how leave hours are calculated for all employees.

4-Day Work Week
10 hrs per working day. Off-days based on schedule. Leave deducts 1.25 days in OrangeHRM.
{% if work_mode == '4day' %} Currently Active {% endif %}
5-Day Work Week
8 hrs per working day. Weekends skipped. Leave deducts 1.0 day in OrangeHRM.
{% if work_mode == '5day' %} Currently Active {% endif %}
Note: Switching modes affects all future leave filings immediately. Existing approved leaves are not recalculated.
